# Orange Ludo

Orange Ludo 是一款面向微信小游戏的模块化飞行棋项目。第一阶段先实现稳定、可测试的人机经典飞行棋；货运、组队、联网和局外经营将在同一规则内核上逐步扩展。

## 当前基线

- 竖屏、固定四方、每方四架飞机。
- 默认仅掷出 6 可以起飞，规则可替换。
- 掷出 6 追加一次投掷。
- 连续第三个 6 结束回合，并按规则处理退回基地的飞机。
- 四架飞机全部到达终点获胜，胜利条件可替换。
- 每次操作限时 15 秒。
- 允许同色飞机叠机，叠机可形成阻挡。
- 第一阶段为 1 名玩家与 3 名明确标识的 AI。

完整规则见 [经典模式规则基线](docs/rules/classic-v0.1.md)。

## 工程目标

1. 游戏规则不依赖 Cocos 场景、节点或动画，可在服务端和自动模拟器中复用。
2. 骰子、移动、碰撞、胜负等结果由权威规则内核判定。
3. 起飞、胜利条件、连续特殊点数和模式扩展均通过规则接口实现。
4. 相同随机种子和操作序列必须得到相同结果。
5. UI 只消费规则事件并播放表现，不反向决定游戏结果。


## 目录

```text
apps/client/              Cocos Creator 微信小游戏客户端（下一阶段接入）
apps/game-server/         联网房间服务（联网阶段接入）
packages/game-core/       与界面无关的规则内核
packages/client-model/    布局、可渲染状态与动画指令
docs/rules/               已确认的规则与待决项
docs/architecture/        架构决策记录
```

## 协作约定

- `main` 必须保持可构建、测试通过。
- 每项功能使用短期分支和 Pull Request。
- 提交前运行 `pnpm check`。
- 不提交 AppSecret、证书、私有环境文件和构建产物。
- 大型美术源文件使用 Git LFS；游戏内资源优先提交经过确认的导出版本。
