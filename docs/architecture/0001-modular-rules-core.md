# ADR-0001：模块化规则内核

状态：接受

## 背景

项目将依次支持经典人机、经典联网、组队和货运模式。起飞条件、连续特殊点数、胜利条件和部分棋盘行为需要在不重写主流程的前提下调整。

## 决策

建立独立于 Cocos Creator 的纯 TypeScript 规则包，并将容易变化的规则定义为接口：

- `TakeoffRule`：是否允许基地飞机起飞。
- `VictoryRule`：是否满足当前模式的胜利条件。
- `ConsecutiveRollRule`：连续特殊点数的处罚。
- 后续增加 `MovementRule`、`CollisionRule`、`LandingRule` 和货运模式规则。

客户端、服务端、AI和自动模拟共用同一套类型与规则实现。服务端在联网模式下拥有最终裁决权。

## 结果

- 数值和常见地方规则可以通过配置或替换模块调整。
- 核心规则可以在没有画面的环境中批量测试。
- 动画与判定解耦，动画被跳过或加速时不会影响结果。
- 后续需要明确规则包的兼容版本，并禁止客户端使用旧规则加入新房间。
